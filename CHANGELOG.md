# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2026-11-15

### Added
- Initial release: schema-aware ghost-text SQL suggestions for MySQL.
- NEXT and FULL suggestion modes, LIST dropdown mode, force-suggest key.
- Learned n-gram model that adapts suggestions to your query history.
- Safety confirmation for `DELETE`/`UPDATE` without `WHERE`, `DROP`, and `TRUNCATE`.
